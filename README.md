# Abrazo al Penna

Página de la cooperadora Abrazo al Penna, del Hospital General de Agudos Dr. José María Penna (Parque Patricios, Buenos Aires).

*Quien abraza, sostiene.*

Proyecto de Práctica Profesional, Facultad de Ciencias Económicas, UBA. El botón de pago de la página es de demostración y no realiza cobros.
